منصة التجارة الإلكترونية الشاملة — متجر رواق

دليل إرشادي تقني شامل يشرح خطوة بخطوة كيفية إعداد، وتثبيت، وتخصيص، ونشر متجرك الإلكتروني على أي سيرفر محلي أو استضافة سحابية بكل سهولة واحترافية.

Node.js & Express MySQL 8.0 httpOnly & CSRF Secure 1-Click COD Direct Checkout عربي (RTL) / EN / FR

1. نظرة عامة والمميزات التنافسية

متجر رواق هو نظام تجارة إلكترونية عربي متكامل وجاهز للإنتاج التجاري، صُمم خصيصاً لتلبية احتياجات التجارة الإلكترونية الحديثة في الجزائر والعالم العربي. يجمع بين سرعة التصفح وتجربة المستخدم الخاطفة، مع أعلى معايير الحماية والأمان على مستوى السيرفر.

شراء فوري بضغطة زر

نموذج الشراء المباشر (1-Click COD) في صفحة كل منتج لمضاعفة مبيعاتك وتخفيض التخلي عن السلة.

دفع محلي عبر البطاقة الذهبية / CIB

تكامل آمن بالكامل مع بوابة Chargily Pay V2 مع تأكيد دفع تلقائي عبر Webhook مشفر.

إشعارات فورية عبر Telegram و WhatsApp

استلام تنبيه صوتي وتفاصيل كل طلب فورياً على هاتفك مع زر تواصل مباشر بواتساب الزبون.

لوحة تحكم وحساب صافي الأرباح

إحصائيات متقدمة، تتبع سعر تكلفة المنتج (Cost Price)، وحساب صافي أرباح المتجر بدقة متناهية.

بوالص الشحن وتصدير التوصيل

طباعة بوالص الشحن الحرارية مباشرة، وتصدير الطلبات CSV بضغطة زر لشركات الشحن (Yalidine, ZR).

وضع داكن وليلي سلس (Dark Mode)

تصميم عصري فائق الجمال يتكيف تلقائياً مع تفضيلات الزبون بدون أي رمشة شاشة (Anti-Flicker).

2. متطلبات السيرفر والاستضافة

لضمان استقرار وسرعة المنصة، تأكد من توفر المتطلبات التالية في بيئة التشغيل لديك:

المكون الإصدار الموصى به الحالة
Node.js الإصدار 18.x أو 20.x أو 22.x LTS مطلوب أساسي
MySQL Database الإصدار 8.0+ أو MariaDB 10.5+ مطلوب أساسي
مدير الحزم (npm) الإصدار 9.x أو أعلى مطلوب
Docker & Compose الإصدار 20+ (اختياري للتشغيل السحابي السريع) اختياري

3. خطوات التثبيت والتشغيل المحلي السريع

اتبع هذه الخطوات البسيطة لتشغيل المتجر محلياً على جهازك خلال أقل من دقيقتين:

الخطوة 1: تثبيت الحزم والمكتبات

Terminal / Command Prompt 
npm install

الخطوة 2: إنشاء وضبط ملف البيئة (.env)

قم بنسخ ملف .env.example إلى ملف جديد باسم .env وضع بيانات الاتصال بقاعدة بيانات MySQL الخاصة بك:

Terminal 
cp .env.example .env

الخطوة 3: ترحيل جداول قاعدة البيانات وملء البيانات التجريبية

Terminal 
npm run migrate
npm run seed:demo

الخطوة 4: تشغيل خادم المتجر

Terminal 
npm start
رائع! المتجر يعمل الآن:
يمكنك فتح المتصفح والدخول إلى المتجر عبر: http://localhost:3000
ولوحة التحكم الإدارية عبر: http://localhost:3000/admin/index.html

4. التشغيل الفوري عبر Docker

إذا كنت تفضل استخدام حاويات Docker المعزولة، فإن المشروع مجهز مسبقاً بملف docker-compose.yml يقوم بإعداد كل من خادم Node.js وقاعدة بيانات MySQL تلقائياً:

Docker Command 
docker compose up --build -d

يقوم Docker بإنشاء قاعدة البيانات وتنفيذ الترحيلات تلقائياً، ويعمل الموقع فوراً على المنفذ 3000.

5. لوحة التحكم وحسابات الدخول

يُنشئ المسؤول الحقيقي عبر متغيرات البيئة أو أمر npm run create-admin، ولا تُترك حسابات تجريبية مفوحة في النسخة المقدمة للمراجعة.

هام جداً قبل إطلاق متجرك الفعلي:
يرجى تغيير كلمة مرور الأدمن عبر لوحة التحكم في صفحة الإعدادات، أو استخدام أمر الإنشاء السريع لتوليد حساب أدمن خاص بك:
npm run create-admin

6. إعداد بوابات الدفع الإلكتروني (Chargily Pay & COD)

يدعم المتجر طريقتين للدفع مهيئتين للتجارة الإلكترونية:

1. الدفع عند الاستلام (Cash On Delivery - COD)

مفعل افتراضياً ولا يتطلب أي إعدادات خارجية. يستطيع الزبون الطلب بضغطة زر واحدة من خلال نموذج الشراء السريع، ويتم حفظ الطلب فوراً بحالة معلق (pending) وتنبيهك بتفاصيله.

2. الدفع بالبطاقة الذهبية / CIB عبر بوابة Chargily Pay V2

لربط بوابة شارجيلي، افتح ملف .env وقم بوضع مفاتيح الربط التي تحصل عليها مجاناً من لوحة تحكم Chargily Pay:

.env 
CHARGILY_PUBLIC_KEY=ed_pk_live_xxxxxxxxxxxxxxxxxxxxxxxx
CHARGILY_SECRET_KEY=ed_sk_live_xxxxxxxxxxxxxxxxxxxxxxxx
CHARGILY_MODE=live
CHARGILY_WEBHOOK_URL=https://yourdomain.com/api/payment/chargily/webhook

7. إشعارات تيليجرام وواتساب الفورية

وداعاً لفقدان الطلبات! يتضمن متجر رواق نظام تنبيه فوري يرسل لك تفاصيل كل طلب إلى هاتفك لحظة بلحظة:

إعداد بوت تيليجرام (Telegram Bot):

  1. أنشئ بوتاً جديداً عبر @BotFather على تيليجرام واحصل على الـ Bot Token.
  2. احصل على معرف الشات الخاص بك (Chat ID) عبر بوت @userinfobot.
  3. أضف البيانات في ملف .env:
.env 
TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRstuVWXyz
TELEGRAM_CHAT_ID=987654321

8. النشر على الاستضافة (cPanel / VPS)

يمكن نشر المنصة على أي استضافة سحابية VPS (مثل Hetzner, DigitalOcean, Contabo) أو استضافات مشتركة تدعم Node.js (مثل cPanel Node.js Selector):

النشر على سيرفر VPS (Ubuntu / Debian):

Ubuntu VPS Setup 
# 1. تثبيت مدير العمليات PM2 لضمان استمرار عمل الموقع دون توقف
npm install -g pm2

# 2. تشغيل التطبيق في الخلفية
pm2 start server.js --name "rewaq"

# 3. تفعيل التشغيل التلقائي عند إعادة إقلاع السيرفر
pm2 startup
pm2 save

9. الأسئلة الشائعة والدعم الفني

س: هل يدعم السكربت تعديل العملة وأسعار الشحن لجميع الولايات؟

ج: نعم، يمكنك تغيير العملة الافتراضية، وضبط أسعار التوصيل الخاصة بكل ولاية (توصيل للمنزل أو توصيل للمكتب) مباشرة وبكل سهولة من خلال لوحة التحكم في صفحة الإعدادات.

س: كيف يمكنني إضافة أكواد التتبع مثل Meta Pixel و TikTok Pixel؟

ج: لا حاجة لتعديل أي كود برمجي! توجه إلى لوحة التحكم > الإعدادات > قسم التسويق، وأدخل معرفات البيكسل الخاصة بك، وسيقوم النظام بتضمينها وتتبع أحداث الشراء (Purchase, AddToCart) تلقائياً.

هل تحتاج إلى مساعدة أو تخصيص إضافي؟
يمكنك التواصل مع فريق الدعم الفني مباشرة عبر منصة بيكاليكا، وسنكون سعداء بالإجابة على استفساراتك ومساعدتك في تثبيت المشروع.
